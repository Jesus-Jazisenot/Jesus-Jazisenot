###  Currently in production

**Insurance policy manager** — built for an agency that tracked renewals in physical
folders and a spreadsheet. In daily use, managing **273 policies across 4 agents**.

- Imports the agency's existing Excel and classifies every renewal from free-text notes
- Automatic reminders ~30 days before a policy lapses, de-duplicated so the same period
  is never announced twice
- Role-based access: each agent sees only their own book, the owner sees everything
- Vercel + Supabase, and it works like an app on the phone

The repository is private because it holds a client's data. Happy to walk you through
the demo instance, which runs on invented records.
